## International SEO (phase 2)

**Current:** Single URL, bilingual UI via toggle — acceptable for MVP; crawlers primarily see English meta.

**Recommended migration:**

```
/en/shree-yantra  ↔  /hi/shree-yantra
```

With bidirectional `hreflang`, `x-default` → `/en/...`, and human-quality Hindi copy (not machine-only).

## Competitor framework

For each target SERP (Shree Yantra, Kundli app, Panchang):

1. Top 5 results — content depth, schema, UX, trust signals  
2. Gap — what they miss (e.g. responsible disclaimers, bilingual UX, live Panchang)  
3. “Better than SERP” — original diagrams, verified citations, app integration  

**Do not copy** competitor text.
