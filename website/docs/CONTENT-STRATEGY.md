# Content Strategy — Shree Yantra Astrology

## Principles

1. **People first** — every page must help a real visitor  
2. **No thin pages** — do not publish until a topic has unique depth  
3. **Tradition vs fact** — label beliefs clearly; no guaranteed outcomes  
4. **No fabricated citations** — use `[citation placeholder]` until verified  
5. **Bilingual quality** — Hindi must read naturally; avoid raw machine translation

## Content refresh triggers

- Legal/subscription pricing change → `/app`, `/help`, FAQ  
- App feature launch → `/services`, `/app`, home sections  
- Search Console shows high impressions / low CTR → rewrite title + intro  
- Competitor SERP adds substantial depth → gap analysis, then one better page
